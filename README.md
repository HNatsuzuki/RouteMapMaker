# 路線図メーカー/Route-Map-Maker

このリポジトリは [RouteMapMaker](https://github.com/teamhimeh/RouteMapMaker) を基に改変を加えたものです。

## 変更内容
- UIフォントの設定機能を追加
- 設定変更時の内部処理変更
- セーブデータ読み書きの内部処理変更
- 描画時の内部処理変更
- 運転系統の始点・終点の座標計算方法変更

## Changes
- Added: UI font customization feature.
- Changed: The handling of settings modifications.
- Changed: The handling of save data I/O operations.
- Changed: The handling of map rendering.
- Changed: Method for calculating coordinates of start and terminal stations in train routes.
